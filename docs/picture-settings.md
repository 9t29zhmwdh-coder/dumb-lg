# Picture settings

Goal: the TV displays the HDMI signal as faithfully as possible, without extra processing.

**Verification status:** Generic recommendations, not yet checked setting by setting on the 75QNED916QE. Menu labels differ between firmware versions. Treat this as a checklist of what to look for.

## On the TV

1. **Picture mode.** Use Filmmaker Mode (or Cinema) for film and series. Use Game for low latency when gaming. Avoid Vivid and Standard.
2. **Turn off processing that alters the image** for film content: motion smoothing (TruMotion), noise reduction, sharpness boosts, dynamic contrast.
3. **Energy saving off.** Automatic brightness and energy saving dim the picture depending on the room. Switch them off for a stable image.
4. **HDMI Ultra HD Deep Colour on** for the input the Apple TV uses. Without it, 4K HDR at 60 Hz may fall back to a lower format.
5. **Dolby Vision and HDR.** Leave HDR Dolby Vision active. The TV switches mode automatically when the source sends it.
6. **Input label.** Set the input type of the Apple TV port to a device preset if offered. Some versions apply picture adjustments per input.

## On the Apple TV

1. Settings, Video and Audio, Format: choose 4K Dolby Vision if your TV and cable support it, otherwise 4K HDR.
2. Turn on Match Dynamic Range and Match Frame Rate so the TV receives the native format of each video.
3. Run the Color Balance calibration with an iPhone, then compare the result against your taste. It is optional.
4. If you see sparkles or a black screen, run the Apple TV's HDMI test in Video and Audio, and replace the cable if it fails.

## Check

- Play a Dolby Vision title and confirm the TV shows the Dolby Vision indicator when the format starts.
- Test film content in Filmmaker Mode in a darkened room. The image will look warmer than Vivid, which is intended.
