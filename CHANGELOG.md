# Changelog

All notable changes are documented here. Format based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), versioning follows [SemVer](https://semver.org/).

## [0.1.4] - 2026-11-09

### Changed
- Audio guide: eARC in HDMI 3 and the fix PCM to Automatic confirmed on the reference TV
- Roadmap updated

## [0.1.3] - 2026-11-09

### Added
- Audio guide: HDMI 3 is the eARC port of the 75QNED916QE according to LG's specification
- Rooting guide: result of the official firmware search (no download for the Swiss model), recovery consequences

### Changed
- Roadmap: open items updated

## [0.1.2] - 2026-11-09

### Added
- Reference device section in the rooting guide: firmware 04.60.85, update 04.60.92 not installed
- Audio guide: what an ARC link looks like on the TV Home screen

### Changed
- Roadmap updated with the open eARC port question and the USB recovery check

## [0.1.1] - 2026-11-06

### Changed
- Audio routing guide: section for soundbars without an HDMI input (Samsung HW-S60D example), optical cannot carry Atmos

## [0.1.0] - 2026-11-06

### Added
- Guides for picture settings, audio routing (Apple TV, LG TV, soundbar over eARC), privacy settings, network isolation and rooting status
- English and German README
- `tools/style_check.py` with unit tests: checks Markdown for dashes and eszett
- CI with lint, tests and dependency audit, CodeQL and OpenSSF Scorecard workflows, Dependabot
