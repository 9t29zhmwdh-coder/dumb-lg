# Code of Conduct

## Pledge

I as the maintainer pledge to keep this project a respectful, harassment-free space for everyone, regardless of background or experience.

## Standards

Welcome behavior: being respectful, giving and accepting constructive feedback, focusing on what helps the project.

Unacceptable behavior: harassment, insults, personal attacks, publishing other people's private information, and anything that would be inappropriate in a professional setting.

## Enforcement

I remove comments, issues and contributions that break these standards, and I may block repeat offenders. Report a problem through a private [GitHub Security Advisory](https://github.com/9t29zhmwdh-coder/dumb-lg/security/advisories/new) or through the contact on my GitHub profile. I review every report and respond as soon as I can.
