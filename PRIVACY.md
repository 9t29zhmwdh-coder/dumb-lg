# Privacy Policy: dumb-lg

## What I Collect

Nothing. This repository is documentation and a local checker script. The script reads Markdown files on your machine and prints results to your terminal. It makes no network connections and sends no data anywhere.

## What GitHub Collects

When you visit the repository, open issues or pull requests, GitHub processes data under its own privacy policy. I have no influence on that, and I see only what you publish yourself in issues and pull requests.

## Your Part

Please do not post serial numbers, IP addresses, account names or photos of your home in issues. If you did by mistake, tell me and I remove it.

## Changes

If this changes, I update this file and note it in the changelog.
